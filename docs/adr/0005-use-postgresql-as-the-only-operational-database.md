# Use PostgreSQL as the only operational database

The first release stores domain records, source payloads, lexical search data, embeddings, provenance, and jobs in PostgreSQL, using `jsonb`, native full-text search, and pgvector where appropriate. If resumable within-Revision execution is introduced, LangGraph checkpoints will use PostgreSQL too. This trades specialized vector-database features for transactional consistency, simpler local and hosted operations, and direct joins across claims, evidence, revisions, and retrieval results; another store will be introduced only when measured limits justify it.
